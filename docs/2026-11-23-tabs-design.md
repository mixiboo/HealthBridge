# 헬스 브릿지 3탭 구성 (v0.6.0)

작성일: 2026-11-23 · 승인: 사용자 "좋아"

## 정한 것
- 맨 위 인사 카드(유리): "민준의 기록," 고정 + 아래 문구 5초마다 크로스페이드로 기능 소개 (애니메이션 끄면 고정)
- 디자인 시스템 유리 하단바: 🏠 메인 · 📦 옮기기 · 🕘 기록 (메뉴 3개 = 시스템 규칙과 일치)
- 메인: 자동 재생 사용법(앱 안에서 그린 움직이는 장면 슬라이드, 실제 영상 파일 없음), 안 될 때 도움말(펼치기), 권한 상태 카드 + 권한 없을 때 요청 창
- 옮기기: 파일 카드, 빠른 선택(추천/운동만/전부), 항목별 들어있는 개수, 운동 종류 칩, 기간(전체/1년/30일/직접), 고급(애플워치만, 다시 쓰기), 하단 고정 시작 버튼, 진행·완료도 탭 안에서
- 기록: 시각(초 단위), 파일명·크기, 사용한 파일 수(XML 1 + 읽은 경로 파일), 새/이미 있음, 항목별 기록 수, 성공/실패. 폰 안 저장, 30일 지나면 자동 삭제

## 내 판단
- 개수 세기(scan)는 미리보기 때 XML을 한 번 훑으며 type만 센다 (날짜 파싱 없이)
- 기록 저장: filesDir/history.json (org.json), 쓰기·읽기 때 30일 지난 항목 제거
- 운동 종류 필터: ImportOptions.workoutTypes (null = 전부)
- 기록 작성 위치: ImportWorker (성공·실패 모두)
