# 헬스 브릿지 화면 꾸미기 (미리내 크루 디자인 시스템)

작성일: 2026-11-23 · 승인: 사용자 "그 방향으로 가자"

## 목적
헬스 브릿지 화면을 미리내 크루 앱과 같은 "리퀴드 글래스" 느낌으로 바꾼다. 기능은 그대로.

## 정한 것 (사용자 승인)
- 색: 디자인 시스템 기본 시드 "하늘"(#6c9bd2)에서 나온 역할 색 토큰 그대로, 라이트/다크는 폰 설정
- 유리 카드: glass-card 배경 + glass-card-border 1px, 그림자 없음, radius-base 30
- 주요 행동 하나만 채운 버튼(primary), 나머지는 외곽선 버튼
- 옮길 항목: 체크박스 대신 칩처럼 누르는 카드 (선택 = secondary-container)
- 말투: 해요체, 인사말 "민준의 기록,", 짧은 동사 버튼
- 움직임: 화면 전환 페이드 (easeOutCubic 340ms), 폰 애니메이션 끄기 설정 존중
- 유리 하단바는 넣지 않음 (한 줄 흐름 앱)

## 고려한 방법
- **토큰을 Compose 테마로 옮기고 공용 컴포넌트(GlassCard, 버튼, OptionChip)로 화면 재구성** ✅ — 디자인 시스템이 정한 값을 한 곳에서 관리
- 화면마다 색·모양을 직접 지정 — 중복, 다크 모드 누락 위험
- Material You 동적 색(배경화면 색) — 디자인 시스템과 달라져서 제외

## 내 판단 (만드는 사람)
- 아이콘: Material Icons 코어(Outlined) 사용, 이모지는 말투 보조로만
- 앱 아이콘 변경: 사용자가 답하지 않아 이번 범위에서 제외
- 글꼴: 기기 기본 글꼴(디자인 시스템 규칙), body-medium 15sp/1.6, body-small 13sp/1.6
